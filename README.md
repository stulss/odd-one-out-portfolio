## 🚀 빠른 실행 방법

1. **로컬 더블클릭 실행**:
   - `포트폴리오_실행하기.bat` 또는 바탕화면의 `오리지널감별국_포트폴리오_열기.bat`을 더블클릭하면 즉시 기본 브라우저에서 포트폴리오가 열립니다.
   - `index.html` 파일을 크롬/엣지 브라우저로 직접 드래그 앤 드롭해도 외부 서버 없이 100% 정상 작동합니다.

2. **로컬 서버 실행 (선택 사항)**:
   ```bash
   npx serve .
   ```

3. **온라인 배포**:
   - GitHub Repository에 푸시한 뒤 Vercel 또는 GitHub Pages에 연결하면 정적 웹사이트로 1분 만에 배포됩니다.

## 🌟 포트폴리오 웹사이트의 핵심 기능

1. **라이브 플레이 임베드**: 실제 배포된 게임(`https://odd-one-out-nine.vercel.app/`)을 화면 내에서 직접 플레이 가능.
2. **10종 차이 축 & 지각 임계값 시뮬레이터 (Interactive Difference Lab)**: 색조, 밝기, 회전, 크기 등 10개 축과 난이도 슬라이더를 직접 조작하며 수학적 공정성을 체감하는 인터랙티브 위젯 내장.
3. **STAR 방식 8대 트러블슈팅**: 상황(S) - 목표(T) - 행동(A) - 결과(R) 및 Before/After 코드 비교, 핵심 Insight 제공.
4. **4대 아키텍처 벤토 그리드(Bento Grid)**: 0 Image/0 Audio/0 Server, 1 Loop rAF, Three.js 싱글톤 WebGL 등 기술적 깊이 전달.
5. **AI 협업 및 비판적 검증 섹션**: 단순 AI 생성 코드가 아닌, 엔지니어의 주도적 판단과 반려 사례 기록.
6. **다크/라이트 모드 & 반응형 지원**: 모바일 화면부터 4K 와이드 모니터까지 완벽 대응.
